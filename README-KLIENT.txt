МЕССЕНДЖЕР «КОНТУР» — КАК ЗАПУСТИТЬ (Windows)
=============================================

1. Скопируйте всю папку на компьютер с Windows.
2. Запустите KonturServer.exe (двойной клик).
   • Появится чёрное окно сервера и откроется окно мессенджера.
   • В окне сервера показаны адреса: http://localhost:4000 и http://<ваш IP>:4000
3. Чтобы подключить друзей в той же сети (Wi-Fi/кабель):
   • пусть откроют в браузере http://<ваш IP>:4000  (например http://192.168.1.10:4000)
   • или запустят KonturServer.exe у себя — но тогда у каждого будет свой сервер;
     чтобы чаты были общими, сервер должен быть один — у вас.
4. На экране входа нажмите «Регистрация» и создайте аккаунт (логин + пароль, 5 секунд).
   Сервер стартует без демо-чатов, демо-людей и ботов — весь чат ваш.

Полезные флаги (можно добавить в ярлык):
   KonturServer.exe --port 4100      другой порт
   KonturServer.exe --browser        открыть в обычном браузере, а не в окне-приложении
   KonturServer.exe --no-open        не открывать окно клиента
   KonturServer.exe --data D:\chat   где хранить историю и файлы
   KonturServer.exe --closed         закрыть регистрацию новых пользователей
   KonturServer.exe --demo           показать демо-стенд (аккаунты anya/boris/vera/gleb,
                                     пароль demo1234, бот @bot, готовая группа с историей)

Сбросить все данные: удалите папку ниже (или запустите scripts\reset-data.js с Node.js)
База данных по умолчанию: %LOCALAPPDATA%\Kontur\data\db.json
Загруженные файлы:        %LOCALAPPDATA%\Kontur\data\uploads\

Windows может спросить разрешение брандмауэра — разрешите для частных сетей,
иначе друзья не смогут подключиться.

МЕССЕНДЖЕР «КОНТУР» — КАК ЗАПУСТИТЬ (Windows)
=============================================

1. Скопируйте всю папку на компьютер с Windows.
2. Запустите KonturServer.exe (двойной клик).
   • Появится чёрное окно сервера и откроется окно мессенджера.
   • В окне сервера показаны адреса: http://localhost:4000 и http://<ваш IP>:4000
3. Чтобы подключить друзей в той же сети (Wi-Fi/кабель):
   • пусть откроют в браузере http://<ваш IP>:4000  (например http://192.168.1.10:4000)
   • или запустят KonturServer.exe у себя — но тогда у каждого будет свой сервер;
     чтобы чаты были общими, сервер должен быть один — у вас.
4. На экране входа нажмите «Регистрация» и создайте аккаунт (логин + пароль, 5 секунд).
   Сервер стартует без демо-чатов, демо-людей и ботов — весь чат ваш.

Полезные флаги (можно добавить в ярлык):
   KonturServer.exe --port 4100      другой порт
   KonturServer.exe --browser        открыть в обычном браузере, а не в окне-приложении
   KonturServer.exe --no-open        не открывать окно клиента
   KonturServer.exe --data D:\chat   где хранить историю и файлы
   KonturServer.exe --closed         закрыть регистрацию новых пользователей
   KonturServer.exe --demo           показать демо-стенд (аккаунты anya/boris/vera/gleb,
                                     пароль demo1234, бот @bot, готовая группа с историей)
   KonturServer.exe --fresh          один раз: полностью стереть базу и файлы
                                     (сервер запустится с чистого листа)
   KonturServer.exe --https          включить HTTPS (камера/микрофон/демонстрация экрана
                                     в браузере по IP работают только так — сертификат
                                     создаётся автоматически, браузер попросит подтвердить)

ЗВОНКИ И КАМЕРА
   • В окне-приложении (его открывает сам .exe) камера, микрофон и демонстрация экрана
     работают сразу — разрешения выданы заранее, HTTPS не нужен.
   • Если вы открыли мессенджер в браузере по адресу http://192.168.x.x:порт — камера и
     экран заблокированы самим браузером. Запустите сервер как KonturServer.exe --https
     и откройте https://<ваш IP>:порт (или заходите через окно-приложение).
   • На http://localhost:4000 браузер доступ к камере даёт и без HTTPS.
   • Микрофон, камеру и динамики можно выбрать в «Настройках» → «Звук и видео»,
     там же кнопка проверки микрофона с индикатором уровня.

ПОЛНОСТЬЮ ОЧИСТИТЬ СЕРВЕР (удалить аккаунты, чаты, файлы)
   1) закройте KonturServer.exe;
   2) двойной клик по reset-data.bat («Очистить данные», лежит рядом с .exe) → напишите y и Enter;
   3) запустите KonturServer.exe заново — база пустая, регистрируйтесь заново.

   Вариант без .bat: запустите один раз KonturServer.exe --fresh
   Вариант руками: удалите папку %LOCALAPPDATA%\Kontur\data

ЕСЛИ ПОСЛЕ ОБНОВЛЕНИЯ ВСЁ ПО-СТАРОМУ
   • Версия видна на экране входа («версия клиента: …») и в «Настройках» → «Служебное»
     (там же видно версию сервера).
   • Если у вас открыт браузер, а не окно-приложение — нажмите Ctrl+F5: браузер
     держит старый файл в кэше. Начиная с v1.0.3 сервер отдаёт клиент с запретом
     кэширования, поэтому это происходит только при переходе со старой версии.
База данных по умолчанию: %LOCALAPPDATA%\Kontur\data\db.json
Загруженные файлы:        %LOCALAPPDATA%\Kontur\data\uploads\

Windows может спросить разрешение брандмауэра — разрешите для частных сетей,
иначе друзья не смогут подключиться.

# 📱 «Контур» для Android — сервер прямо в телефоне

Это приложение — не просто клиент. Внутри APK лежит настоящий **Node.js**, который запускает
сервер мессенджера (`server/server.js`) на самом телефоне. Приложение поднимает сервер,
затем открывает в себе обычный веб-клиент — тот же самый, что и на компьютере.

```
экран запуска (mobile/www)                     веб-клиент (web/)
        │  CapacitorNodeJS.start()
        ▼
  Node.js внутри приложения ──► server/server.js ──► http://127.0.0.1:4000
        │                                │
        │  bridge.channel.send           └─► друзья в Wi-Fi: http://192.168.x.x:4000
        ▼
  «сервер готов» → WebView открывает мессенджер
```

## Что где лежит

| Путь | Назначение |
| --- | --- |
| `package.json` | зависимости и команды сборки (Capacitor 8 + `capacitor-nodejs`) |
| `capacitor.config.json` | настройки приложения: `app.kontur.messenger`, имя «Контур», `webDir: www` |
| `www/` | экран запуска (`index.html`, `launcher.js`, `launcher.css`, `icon.png`) |
| `www/nodejs/` | **собирается** командой `npm run prepare:node` — сервер + веб-клиент + express/ws |
| `node/mobile-server.js` | точка входа Node.js внутри телефона: порт, папка данных, запуск сервера |
| `scripts/prepare-nodejs.mjs` | сборка `www/nodejs/` из `server/` и `web/` (одна копия кода на все платформы) |
| `scripts/make-icons.py` | значки Android из `assets/icon-1024.png` (нужны Pillow, numpy, scipy) |
| `android/` | Android-проект: свой плагин, фоновая служба, манифест, подпись |
| `android/app/src/main/java/app/kontur/messenger/` | `KonturAppPlugin` (переходы, фон, разрешения) и `KonturServerService` |
| `android/keystore/` | ключ подписи, чтобы новые версии ставились обновлением |

## Сборка APK

Всё делается в GitHub Actions — workflow **«Сборка .exe, APK и релиз»**, задача `android-apk`.
Она ставит Node 22, JDK 21 и Android SDK 36, собирает Node-бандл и запускает Gradle.
Готовый файл `Kontur-Android-<версия>.apk` попадает в артефакты и в релиз на странице
[Releases](https://github.com/smells1k/kontur-messenger/releases/latest).

Локально (нужны Node 22+, JDK 21, Android SDK):

```bash
cd mobile
npm install
npm run prepare:node      # сервер + веб-клиент внутрь бандла
npm run sync              # то же + перенос в Android-проект (cap sync)
npm run build:apk         # release APK (подпись ключом проекта)
npm run build:apk:debug   # debug APK — быстрее, для проверки
npm run check             # проверить, что бандл собран целиком
```

## Что умеет приложение

* **Сервер в телефоне.** Внутри APK — Node.js и тот же сервер `server/server.js` со всеми
  функциями: чаты, файлы, звонки, синхронизация. Данные лежат в личной папке приложения.
* **Экран запуска** — состояние сервера, адрес для друзей в Wi-Fi, «Скопировать»,
  «Поделиться», «Держать в фоне» и журнал запуска.
* **Фоновый режим** — служба с постоянным уведомлением держит сервер живым, пока приложение
  свёрнуто (кнопка «Остановить» есть прямо в уведомлении).
* **Разрешения** камеры и микрофона запрашиваются заранее, чтобы звонок начинался сразу.
* **Подключение к чужому серверу** — введите адрес компьютера друга на экране запуска,
  приложение откроет мессенджер к нему (интернет-ссылки `https://…trycloudflare.com` тоже работают).
* **Смена камеры** во время звонка (передняя/задняя) без разрыва соединения.

## Чего в мобильной версии нет

* **Демонстрации экрана** — Android WebView её не поддерживает, в звонке кнопка скрыта.
* **Интернет-адреса для друзей** — телефон доступен в своей сети. Для подключений из другой
  сети держите сервер на компьютере с ключом `--tunnel` и подключайтесь к нему с телефона.
* **x86-устройств** (старые эмуляторы) — движок Node.js собран под `arm64-v8a`, `armeabi-v7a`
  и `x86_64`.

## Подпись и обновления

APK подписывается ключом проекта `android/keystore/kontur-release.jks` (пароль там же, в
`keystore.properties`). Ключ лежит в репозитории намеренно: Android отказывается устанавливать
обновление, подписанное другим ключом. Так новые версии ставятся «поверх» и не теряют переписку.

## Отладка на телефоне

```bash
cd mobile
npm run android:open      # откроет проект в Android Studio
```

Журнал сервера виден в самом приложении на экране запуска («Журнал запуска»), а также
`chrome://inspect` по USB — WebView отлаживается как обычная страница.

# Ключ подписи «Контура»

`kontur-release.jks` — ключ, которым подписываются сборки Android-приложения.
Он лежит в репозитории сознательно: иначе каждая сборка в GitHub Actions
получала бы новый ключ, и Android отказывался бы устанавливать обновление
поверх уже установленного приложения («подписи не совпадают»).

* хранилище: PKCS12, алиас `kontur`
* пароль хранилища и ключа: `kontur-messenger` (см. `../keystore.properties`)
* срок действия: 30 лет

Секретом этот ключ не является: он не даёт доступа ни к серверу, ни к данным
пользователей. Если понадобится по-настоящему закрытая подпись — замените файл
своим ключом и пересоберите APK (тогда обновление нужно будет ставить заново).
